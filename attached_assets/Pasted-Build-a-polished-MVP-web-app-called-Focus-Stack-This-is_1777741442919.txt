Build a polished MVP web app called Focus Stack.

This is a compact-first, local-first desktop productivity app for daily prioritization. It should feel like a small, focused utility app, not a sprawling enterprise dashboard. Think closer to the footprint and behavioral feel of a Pomodoro timer app, but with richer daily planning functionality. Full-screen should be supported, but the product must be designed for a compact default window first.

Important product context:
- Personal app only, not team-based
- No account, no login, no signup
- Open source friendly
- No exporting in MVP
- No backend required for MVP
- All data should live locally in the app
- Optional calendar import can exist later, but do not depend on it
- The core job is helping a user decide what matters today in under 5 minutes
- The app should support zero-priority days
- The app should support subtle carryover of incomplete priorities
- The app should include a Focus Timer, Trends view, Settings, and brief end-of-day check-in

Primary user:
Students first, especially busy graduate students, but also useful for employees, consultants, operators, and founders managing competing priorities.

Build target:
Create a working frontend MVP with realistic local state, seeded demo data, reusable components, responsive compact-first layouts, and polished UI. Do not make this a bare wireframe. Make it feel like a believable real app.

Tech and architecture requirements:
- Use React + TypeScript
- Use Tailwind CSS
- Use a simple local state approach suitable for MVP
- Use IndexedDB or a clearly structured local persistence layer if straightforward, otherwise use a clean local mock store abstraction that can later be swapped to IndexedDB
- No fake backend API dependency
- Build as if this can later become a PWA
- Code should be clean, modular, and easy to extend
- Organize by features/screens/components, not one giant file

Design direction:
The UI should feel premium, quiet, modern, and compact. Do not use loud startup gradients, neon effects, purple AI aesthetics, or sci-fi UI. Use a soft sage-gray and off-white palette with charcoal actions. The app should visually reflect calm prioritization and deliberate focus.

This app must be designed first for a compact desktop app window, roughly:

- Height: 820 to 900 px

This is the primary design target.

- Full screen is allowed, but should feel like an expanded version of the compact app, not a different product

Core behavior and local logic:
- Users create priorities using natural-language quick add
- Only title is required initially
- System parses text into a draft priority card
- System suggests bucket and recommendation label before save
- Users can override all recommendations
- Incomplete priorities carry over by default
- Deferred priorities carry to tomorrow by default
- Completed one-off priorities with no due date should not repopulate
- Recurring priorities should prompt the user each day whether to include them
- Calendar events should become draft priority cards, not active priorities
- Zero-priority days are allowed
- Completed priorities move into Completed Today
- Other candidate items remain in a collapsed section
